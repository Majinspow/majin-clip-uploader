Privacy Policy

Last updated: October 11, 2026

What data is used

When the user signs in with TikTok, the tool receives an access token, the user's open ID and basic profile information (display name, avatar). The tool uploads only the video files and captions the user selects.

YouTube API Services

The tool uses YouTube API Services to upload the owner's own short videos to the owner's own YouTube channel. When the user signs in with Google, the tool receives an OAuth access token and refresh token (scopes: youtube.upload, youtube.readonly) and reads the channel ID and channel title to show which channel is connected. It does not read, store or share any other YouTube or Google data. By using the YouTube features of this tool, users agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Where data is stored

All data, including access tokens, is stored only locally on the user's own computer. No data is sent to any server operated by the tool's owner, and nothing is shared with or sold to third parties. Data is sent only to TikTok and YouTube in order to publish the selected videos. Tokens are stored encrypted (Windows DPAPI).

This website

This website is hosted on GitHub Pages and does not use cookies, analytics or tracking. The sign-in callback page only displays the authorization code in the user's own browser so it can be copied into the local tool.

Deleting data

The user can revoke access at any time in the TikTok app under Settings and privacy > Security > Apps and services, and can delete the locally stored token in the tool. Google/YouTube access can be revoked at any time at security.google.com/settings/security/permissions; the tool's "Disconnect" button deletes the stored Google tokens immediately. Locally stored API data is refreshed or deleted within 30 days.
