Privacy Policy

Last updated: October 10, 2026

What data is used

When the user signs in with TikTok, the tool receives an access token, the user's open ID and basic profile information (display name, avatar). The tool uploads only the video files and captions the user selects.

Where data is stored

All data, including access tokens, is stored only locally on the user's own computer. No data is sent to any server operated by the tool's owner, and nothing is shared with or sold to third parties. Data is sent only to TikTok in order to publish the selected videos.

This website

This website is hosted on GitHub Pages and does not use cookies, analytics or tracking. The sign-in callback page only displays the authorization code in the user's own browser so it can be copied into the local tool.

Deleting data

The user can revoke access at any time in the TikTok app under Settings and privacy > Security > Apps and services, and can delete the locally stored token in the tool.
